# seggwat-topcoat

SeggWat feature voting, roadmap and changelog as server-rendered [Topcoat](https://github.com/tokio-rs/topcoat) components: `idea_board`, `roadmap_board`, `changelog_feed`. Signed-in visitors load the `<seggwat-board>` vote module from your asset bundle; logged-out visitors need no script.

See the [SDK README](https://github.com/SeggWat/seggwat-sdk) for setup.
