# seggwat

Types for SeggWat's public board API, plus (feature `client`) a cached server-side client, safe Markdown rendering for changelog bodies and HS256 end-user token signing.

Render the data with [`seggwat-topcoat`](https://crates.io/crates/seggwat-topcoat) or [`seggwat-dioxus`](https://crates.io/crates/seggwat-dioxus). See the [SDK README](https://github.com/SeggWat/seggwat-sdk) for setup.
